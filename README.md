# CMP 131 — Turtle Graphics Project 3

## Python Turtle House Challenge

A beginner group project with **two student-written functions**. Work in groups of 2–3 to design a colorful themed house.

Start with [the project instructions](CMP131-Turtle-Graphic-Project-3.md). Read [the AI-use policy](AI-Use-Policy.md) before beginning.

## Files

- `turtle_house.py` — write your program here.
- `CMP131-Turtle-Graphic-Project-3.md` — requirements, steps, hints, and submission checklist.
- `AI-Use-Report.md` — complete honestly as a group, including when no AI was used.
- `.github/copilot-instructions.md` — tutoring guidance.
- `.vscode/` — editor settings, extension recommendations, and run configuration.

## Get started

1. Create your own copy of this repository using **Use this template** if available, or fork it. Use one shared repository per group.
2. Clone your group's repository and open the entire folder in VS Code.
3. Install Python 3 and the recommended Python extensions. Run **Python: Select Interpreter** from the Command Palette.
4. Open `turtle_house.py` and write your program. Use **Run Python File in Terminal**, or press **F5** and choose **Run Turtle House**.
5. Test the drawing, complete the AI-use report, then commit and push your work.
6. Submit your group's repository link and drawing screenshot through Blackboard Ultra as directed.

Keep your Python file in the repository root. Do not name a file `turtle.py`, because that conflicts with Python's turtle module.

**Run locally on a computer with a desktop graphics window.** Turtle uses Tkinter, which is included with many Python installations. If you see a Tkinter error, ask the instructor for setup help. A browser-only editor or ordinary headless Codespace will not display the turtle window without additional setup.

**Do not push student solutions to the instructor's starter repository.**
